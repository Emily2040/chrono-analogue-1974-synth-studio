# Chrono Analogue // System 1974 — 改良版シングルショット完全制作プロンプト（日本語）

[English](en.md) · [简体中文](zh-CN.md) · [日本語](ja.md) · [한국어](ko.md) · [初期英語ブリーフ](original-brief.en.txt)

このファイルには、Google Antigravity 上の **Gemini 4 Argon** を用いて、演奏可能な 1974 年式 3D モジュラー・アナログ・シンセサイザー＆ 180g ダイレクトドライブ・ターンテーブル・スタジオ（**Chrono Analogue // System 1974**）と、2 分間のフル HD（`1920×1080`・`60.0 fps`）4 大交響曲ショーケース動画を一括構築するための**改良版自然言語マスタープロンプト**を収録しています。

## 初期プロンプトから最終版に至る 5 段階の洗練プロセス

実際の開発では、最初の [`original-brief.en.txt`](original-brief.en.txt) から出発し、以下の 5 段階の検証・改修サイクルを経て完成に至りました。下記の改良版プロンプトには、途中で判明したすべての設計判断とバグ対策があらかじめ組み込まれているため、コピー＆ペーストするだけで途中の試行錯誤を繰り返さずに最終品質を再現できます。

1. **ステージ 1（パイプライン検証と 3 つのスキーマ検証済み共有レコード）**：ヘッドレス Blender 5.2 (`bpy`) から `calibration_knob.glb` を書き出し、Three.js でのピッキングと Web Audio の発音確認を最初に実証。`contract.json`（`0.1 m` 基準単位、`0.8 m` ラック幅、`15°` 後傾パネル、16 個のノブ、12 個のパッチジャック、`C3–C5` 25 鍵ヒンジ鍵盤）、`world.json`（全 64 エンティティ）、`progress.json` を単一の信頼できる情報源として定義しました。
2. **ステージ 2（2 段構成 HUD、鍵盤の立体造形、スタジオ背景の完結）**：初期の上部テキスト重なりを解消するため 2 段構成のハードウェア・ヘッダーに再設計。平面的な箱だった鍵盤をウォーターフォール白鍵・面取り黒鍵・深紅のフェルトレールに刷新し、`3.80 m × 1.60 m` のコンソールデスクと L 字型ウォルナット音響スラット壁を配置して、どのカメラ角度からも背景の黒い空白が見えないようにしました。
3. **ステージ 3（16 枚の PBR テクスチャと `backdrop-filter` を排した 60 FPS ハードウェア UI）**：ブラウザの描画遅延を引き起こしていた CSS の `backdrop-filter: blur()` と毎フレームのレイキャストを廃止し、Nano Banana で生成したヘアライン黒ブロンズのラックパネル質感（`ui_hardware_console_skin.png`）と 30 Hz スロットリングのホバー判定に置き換えました。全 162 メッシュに 3 セグメントの `bmesh` ベベル、スムーズ法線、接線計算、クリアコート、16 枚の高解像度 PBR マップ（アルベド／Sobel 法線／ラフネス／メタリック）を適用しました。
4. **ステージ 4（1974 年式ダークルーム照明、木工長軸 UV 整列、ジャック間コリドー配線）**：Three.js 標準の `RoomEnvironment()` は天井が白く発光しているため、水平な 180g レコード盤やデスク面が白っぽく曇る原因になっていました。そこで天井を暗色（`0x060709`）にしたカスタム 1974 スタジオ・ソフトボックス PMREM 環境マップとストロボプリズムのネオンアンバー点光源を構築し、水平金属面の `specularIntensity` を抑えました。また、ベベル処理後に各板面の最長軸に沿って `V` 座標を展開することで木目の方向を正しく揃え、240 セグメント・2 トラックのストロボプラッターと肉抜きマグネシウム・ヘッドシェルを造形し、ベイを跨ぐ長尺パッチケーブルを上下ジャック列中間の水平コリドー（`corridorY`）へ通すとともに、同一ジャックへの複数プラグ接続を法線方向 `+0.014 m` の同軸スタックで解決しました。
5. **ステージ 5（2 分間・1080p60 の 4 大交響曲ショーケース動画）**：48 kHz ステレオのポリフォニック・ラダーシンセ＋コード追従型レコード伴奏エンジン（`scripts/showcase_choreography.py`）と、セグメント境界に 30 フレームのプリロール・ウォームアップを備えた 4 ワーカー並列ヘッドレス Chrome WebGL2 レンダラー（`scripts/render_social_showcase_1080p60.py`）により、全 7,200 フレームの `showcase-1080p60.mp4` を生成しました。

## コピー＆ペースト用シングルショット・マスタープロンプト（日本語版）

以下のコードブロック全文を Google Antigravity の **Gemini 4 Argon** セッションに貼り付けて実行してください：

```text
1974 年式のモジュラー・アナログ・シンセサイザーと 180g ダイレクトドライブ・ターンテーブルを備えたフォトリアルな 3D 演奏スタジオ（「CHRONO ANALOGUE // SYSTEM 1974」）を構築し、4 つのクラシック交響曲を演奏する 2 分間（120.00 秒・7,200 フレーム）のフル HD（1920x1080 @ 60.0 fps）ソーシャルメディア用ショーケース動画をレンダリングしてください。全体のディレクションと統合には Gemini 4 Argon を使用し、編集可能なベベル付き 3D アセットの作成にはヘッドレス Blender 5.2 Python (bpy)、16 枚の PBR テクスチャ生成には Nano Banana (image-generator) と決定論的 Python Sobel/PBR 合成、60 FPS のインタラクションには Three.js (r169 MeshPhysicalMaterial)、リアルタイム音響には Web Audio API、1080p60 H.264/AAC エンコードには FFmpeg を使用してください。

1. スキーマ検証済み共有レコードとパイプラインの事前実証
プロジェクトルートに 3 つの JSON スキーマ検証済みレコードを維持し、ランタイム検証用に public/ にも同期してください：
- contract.json：0.1 m 基準単位（glTF 出力時は 1.0 m）、0.8 m ラック幅（0.2 m × 4 ベイ：VCO BANK、VCF 24 dB/OCT LADDER FILTER、CONTOUR ADSR/VCA、MODULATION LFO & BBD DELAY）、15.0 度のフェイスプレート後傾角、Blender（+X 右・-Y 前・+Z 上）から Three.js（+X 右・+Y 上・+Z 前）への座標変換、16 個のノブ（ローカル Z 軸周り -135 度〜+135 度）、12 個の 3.5mm パッチソケット（上段 [OUT] 6 個：VCO 1 OUT、VCO 2 OUT、VCF OUT、ENV CV OUT、LFO CV OUT、PHONO OUT／下段 [IN] 6 個：VCO PITCH CV、VCF AUDIO IN、VCF CUTOFF CV、VCA AUDIO IN、VCA GAIN CV、DELAY IN）、C3〜C5 の 25 鍵ヒンジ鍵盤（MIDI 48〜72、後端ローカル +X 軸周り +4.5 度回転）、および Turntable_Platter / Tonearm_Gimbal / Tonearm_Headshell / Turntable_SpeedSwitch / Turntable_StartStop のインターフェース定義。
- world.json：全 64 エンティティの固定 ID、親子階層、座標系付きトランスフォーム、16 枚のテクスチャパス、5 つのカメラプリセット（opening_studio、synth_rack_closeup、patch_and_keys、turntable_closeup、side_profile_tilt）、および確定したビジュアル仕様。
- progress.json：現在のマイルストーン、役割分担、完了・未完了タスク、検証エビデンスのパス。
全アセットを構築する前に、まず blender/calibration_knob.blend から public/assets/models/calibration_knob.glb を書き出し、Three.js でのノブ操作と Web Audio の発音確認を行ってください。

2. 木工長軸 UV 整列・3D ベベル造形・16 枚の PBR テクスチャパイプライン
- Nano Banana でオイル仕上げのアメリカン・ブラックウォルナット木目、ガンメタル・ヘアラインのターンテーブル天板、1974 年プログレッシブ電子音楽 LP ジャケット画、エスプレッソ・ペブルレザー調のスタジオデスク、ヘアライン黒ブロンズの UI コンソールスキンを生成し、scripts/prepare_textures.py で 16 枚の高解像度 PBR マップ（アルベド、Sobel 法線、ラフネス、メタリック、およびレコード盤の放射状グルーヴ法線マップ）を合成してください。
- scripts/build_studio_assets.py では、すべての矩形ボード、プリンス、鍵盤、スラットに対して先に 3 セグメントの bmesh ベベルを適用し、その後各ポリゴン面の最長軸に沿って V 座標をマッピングすることで、水平なレールや台座縁には水平方向の木目、垂直なサイドチークや音響スラットには垂直方向の木目が正しく走るようにしてください。
- シンセのフェイスプレート（synth_faceplate_albedo.png）は #101215 のチャコールブラック・アルマイトとし、クリーム色のシルクスクリーン目盛り（#faf2e0）、アンバー／シアンの見出し、ベイ境界の刻印、四隅のネジ、全 16 ノブ下の金属シャフトワッシャーを描画してください。シルク印刷のある mat_anodised_panel と、印刷のにじみがないマットなキーベッド枠用の mat_anodised_trim を明確に分離してください。
- 56 セグメントの縦溝ベークライトノブ（スピン加工アルミキャップ＋クリーム色インジケーター付き）、32 セグメントの六角ナット 3.5mm ジャック、深紅のフェルトストリップを備えた 25 鍵の立体鍵盤、33 1/3 と 45 RPM の 2 列ストロボドットと黒色溝を持つ 240 セグメントのアルミダイキャスト・プラッター、ネオンアンバーのレンズが光るプリズム・ストロボタワー、埋め込み式 45 RPM アダプター、油圧式キューイングレバー、36 ステップの S 字クローム・トーンアーム、スリット入りマグネシウム・ヘッドシェル、見開き LP ジャケットスタンド、そして丸みのあるウォルナット・ブルノーズ縁と L 字型ウォルナット音響スラット壁（slat_i = -32〜32、腰壁レール付きで背景の隙間ゼロ）を備えた 3.80 m × 1.60 m のスタジオデスクを造形してください。

3. 1974 年式ダークルーム PMREM 照明と 60 FPS ハードウェア・コンソール UI
- 水平なレコード盤やデスク面が白っぽく反射してしまう Three.js 標準の RoomEnvironment() は使用しないでください。暗い吸音天井（0x060709）と、浅い角度から照らす 3200K ウォームキー、クールシアンのフィル、アンバーのリム・ソフトボックスを組み合わせたカスタム 1974 スタジオ PMREM 環境マップを構築し、ストロボプリズム位置にネオンアンバーの PointLight（0xff5e14）を配置してください。
- 全メッシュを接線計算済み（computeTangents）・異方性フィルタリング有効の MeshPhysicalMaterial にアップグレードしてください。mat_vinyl_record は漆黒（0x050507、clearcoat: 0.92、anisotropy: 0.90）に設定して鮮明な扇状のグルーヴ反射を表現し、水平な金属面（mat_turntable_deck、mat_anodised_trim）はグレアを抑えた設定（roughness: 0.58-0.78、specularIntensity: 0.15-0.32）にして強い鏡面白飛びを防いでください。
- CSS の backdrop-filter: blur() は完全に排除してください。上下の HUD バーにはヘアライン黒ブロンズのハードウェアスキン（ui_hardware_console_skin.png）を適用し、非ドラッグ時のホバー・レイキャストと 2D オシロスコープ描画を 30 Hz にスロットリングし、THREE.PCFShadowMap を使用することで、コンソールエラー 0・非推奨警告 0 で安定した 60 FPS を維持してください。

4. WEB AUDIO シンセサイザー、ターンテーブル、ジャック間コリドー配線
- Web Audio API による実音シンセサイザー（連続波形モーフィングとサブオクターブ矩形波を備えたデュアル VCO、サチュレーションドライブ付き 24 dB/oct 共鳴ラダーフィルター、ADSR エンベロープ、LFO、ステレオ BBD ディレイ）と、再生位置を維持したまま 33 1/3 RPM（1.00x）と 45 RPM（1.35x）を切り替えられる 180g レコード・ターンテーブルを実装してください。
- ベイを跨ぐ長尺パッチケーブル（horizDist > 0.26 m）は、上段 [OUT] 列と下段 [IN] 列の中間にある水平コリドー（corridorY = (p0.y + p1.y) * 0.5 - 0.005）を通し、レーンごとの奥行き・高さオフセットを与えて中間のジャック（ENV CV OUT、LFO CV OUT、VCA AUDIO IN、VCA GAIN CV）やラベルを一切隠さないようにしてください。同一ソケットに複数ケーブルを挿す場合は、フェイスプレート法線方向に +0.014 m ずつ同軸スタックさせて Z ファイティングを防いでください。
- scripts/verify_and_capture_rev3.py を実行し、全 64 GLB ノードの一致、G_SELF_TEST（Red->Green）、C3〜C5 のピッチ精度（誤差 0.000 Hz）、不正パッチ拒否ルール、フォーカス喪失時のノート解放、60 FPS テレメトリを検証してください。

5. 2 分間・フル HD 1080p60 の 4 大交響曲ショーケース動画
- scripts/showcase_choreography.py と scripts/render_social_showcase_1080p60.py を作成し、決定論的な 120.00 秒（60.0 fps・7,200 フレーム、1920x1080）のショーケース動画（showcase-1080p60.mp4）と 48 kHz ステレオ WAV マスター（evidence/social_showcase_1974_symphonies_48k.wav）、.srt 字幕、SNS 投稿文を生成してください：
  - 0:00-0:30（第 1 楽章：ベートーヴェン『交響曲第 5 番 ハ短調「運命」』Op. 67）：ライブ・パッチング（VCO 1 + VCO 2 -> VCF、ENV CV -> VCF CUTOFF、計 4 本）と、CUTOFF FREQ（280 Hz -> 7,400 Hz）および LADDER DRIVE（3.8x）のダイナミックなスイープ。
  - 0:30-1:00（第 2 楽章：J.S. バッハ『トッカータとフーガ ニ短調』BWV 565 ／ ヴィヴァルディ『四季より「冬」第 1 楽章』）：カメラ前でのケーブル切り替え（LFO CV -> VCO PITCH CV、VCF OUT -> DELAY IN、計 5 本）、リード／オルガン波形へのモーフィング、25 鍵盤での高速 16 分音符対位法と BBD ステレオエコー。
  - 1:00-1:30（第 3 楽章：モーツァルト『交響曲第 40 番 ト短調』K. 550 ＋ 180g レコード演奏）：PHONO OUT -> VCF AUDIO IN のパッチング（計 5 本）、S 字トーンアームの降下による 33 1/3 RPM レコード再生、1:14.0 での 45 RPM（1.35 倍ピッチ＆テンポ）へのライブ変速とマンハイム・ロケット経過部、1:24.0 での 33 1/3 RPM 復帰。
  - 1:30-2:00（第 4 楽章：ベートーヴェン『交響曲第 9 番「歓喜の歌」フィナーレ』Op. 125）：全 6 個の [OUT] ソケットすべてを全 4 ベイにわたって同時接続するフルラック・パッチ＋ターンテーブル伴奏、CUTOFF FREQ を 11.5 kHz・LADDER DRIVE を 4.2x まで開放するクライマックス。
- 操作中のノブには視差ずれのない 3D デュアルリング・クラウンハイライトを表示し、ケーブル接続中は始点・終点の両ソケットをグリーンで強調し、上下の HUD（上部 96 px・下部 216 px）と重ならないカメラフレーミングを行い、4 並列 Chrome ワーカーのセグメント境界で 30 フレームのプリロール・ウォームアップを行って全 7,200 フレームの連続性を保証してください。
```
